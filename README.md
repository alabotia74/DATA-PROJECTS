# Data Projects — Laura Alfonso

Repositorio con proyectos de análisis y ciencia de datos desarrollados en el marco de la Maestría en Inteligencia Analítica de Datos (Universidad de los Andes) y de forma independiente.

## Proyectos

| Proyecto | Descripción | Stack |
|---|---|---|
| [`ETL/`](./ETL) | Proceso ETL completo para construir un data warehouse dimensional (modelo estrella, SCD tipo 2) a partir de datos de seguros de salud: áreas de servicio, planes de beneficio, condiciones de pago y tipos de beneficio. | Python, PySpark, SQL (MySQL, JDBC) |
| [`MACHINE_LEARNING/NLP_SPOTIFY/`](./MACHINE_LEARNING/NLP_SPOTIFY) | Modelo de regresión para predecir la popularidad de canciones a partir de sus características de audio, con feature engineering, target encoding y ensamble por stacking. | Python, Scikit-learn, XGBoost, LightGBM |
